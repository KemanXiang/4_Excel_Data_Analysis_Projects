# Excel Data Analysis Projects

A collection of Microsoft Excel projects documenting my progression from foundational spreadsheet skills to more comprehensive business analytics and simulation models.

## About This Repository

This repository brings together Excel-based exercises and analytical projects covering data preparation, spreadsheet functions, reporting, visualization, marketing analysis, and decision-making under uncertainty.

The repository is organized into three broad parts:

- **Foundational Excel skills (`01`–`05`):** Smaller exercises focused on core spreadsheet techniques, data cleaning, pivot tables, charts, and dashboards.
- **Applied analytics (`06`–`07`):** More complete projects that use Excel to investigate business questions, build quantitative models, and interpret results.
- **Selected portfolio work (`00`):** A dedicated collection of more developed Excel projects presented as portfolio pieces.

## From Excel Fundamentals to Applied Analytics

The first five numbered folders emphasize practical Excel proficiency: organizing and cleaning data, applying formulas, summarizing information, and communicating findings visually. These smaller exercises provide the technical foundation for the more involved projects that follow.

**`06_Marketing_Analysis`** contains more complete analyses focused on marketing-related questions and the interpretation of business data.

**`07_Simulation_and_Decision_Analytics`** contains 11 projects exploring uncertainty and dynamic behavior through methods such as Monte Carlo simulation, Markov chains, diffusion modeling, and scenario analysis. Applications span marketing, finance, operations, healthcare, and other decision contexts. See the [simulation collection README](./07_Simulation_and_Decision_Analytics/README.md) for project-level descriptions.

**`00Portfolio_Projects`** highlights selected, more developed Excel projects for readers who prefer to start with representative work rather than individual skill-building exercises.

## Notes

Projects vary in scope: some are short exercises intended to demonstrate a specific Excel technique, while others are extended analytical studies. Simulation workbooks may generate different numerical outcomes when recalculated because of random-number formulas.

For detailed assumptions, methodology, and findings, refer to the documentation within each project folder.
